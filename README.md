# Portfolio Risk Analyzer & Optimizer

**A quantitative finance application implementing Modern Portfolio Theory for portfolio analysis, risk assessment, optimization, Monte Carlo simulation, and benchmark comparison.**

---

## Overview

This project demonstrates the practical implementation of **Modern Portfolio Theory (Markowitz, 1952)** — a foundational concept in quantitative finance. The application allows users to:

- Analyze investment portfolios with comprehensive risk metrics
- Optimize asset allocations to maximize risk-adjusted returns
- Visualize the efficient frontier and compare portfolio strategies
- Simulate thousands of random portfolios via Monte Carlo methods
- Compare portfolio performance against the S&P 500 benchmark (SPY)
- Understand correlation structures between assets (before vs. after optimization)
- Detect sector concentration risk with automatic warnings
- Export results to PDF with one click

**Built for:** Aalto University Finance program application portfolio

## Financial Theory

### Modern Portfolio Theory (MPT)

The application implements the core mathematical framework of MPT:

#### 1. Portfolio Expected Return
```
E[R_p] = Σ w_i × μ_i
```
Where:
- `w_i` = weight of asset i
- `μ_i` = expected return of asset i

#### 2. Portfolio Variance (Risk)
```
σ²_p = Σ Σ w_i × w_j × σ_ij
```
Where:
- `σ_ij` = covariance between assets i and j
- Matrix form: σ²_p = w^T Σ w

#### 3. Sharpe Ratio
```
Sharpe = (E[R_p] - r_f) / σ_p
```
Where:
- `r_f` = risk-free rate
- Measures risk-adjusted return

#### 4. Optimization Problem

The optimizer solves a quadratic programming problem:

```
Maximize: (w^T μ - r_f) / √(w^T Σ w)
Subject to:
  Σ w_i = 1           (budget constraint)
  w_i ≥ 0             (no short selling, optional)
```

Solved using **Sequential Least Squares Programming (SLSQP)** from `scipy.optimize`.

#### 5. Monte Carlo Simulation

Random portfolios are generated by sampling weight vectors from a Dirichlet distribution and computing the resulting risk/return profile for each:

```
w ~ Dirichlet(α)    (ensures Σ w_i = 1, w_i ≥ 0)
For each w: compute E[R_p], σ_p, Sharpe
```

This produces an empirical view of the attainable portfolio space and confirms the analytically derived efficient frontier.

## Features

### Four Analysis Modes

| Button | What It Does |
|--------|-------------|
| **Analyze** | Calculates full risk metrics for the current portfolio weights |
| **Optimize** | Finds Max Sharpe, Min Variance, and Equal Weight portfolios + efficient frontier |
| **Monte Carlo** | Simulates 2,000 random portfolios and plots them on the risk/return plane |
| **vs SPY** | Plots cumulative return of the portfolio against the S&P 500 over the selected period |

### Risk Metrics Calculated

| Metric | Description | Formula/Method |
|--------|-------------|----------------|
| **Expected Return** | Annualized mean return | μ × 252 (trading days) |
| **Volatility** | Annualized standard deviation | σ × √252 |
| **Sharpe Ratio** | Risk-adjusted return | (Return - r_f) / Volatility |
| **Sortino Ratio** | Downside risk-adjusted return | (Return - r_f) / Downside Deviation |
| **VaR (95%)** | Value at Risk | Parametric: μ - 1.645σ |
| **CVaR (95%)** | Conditional VaR / Expected Shortfall | Mean of returns below VaR threshold |
| **Max Drawdown** | Maximum peak-to-trough decline | Rolling calculation |
| **Beta** | Market sensitivity | Cov(asset, market) / Var(market) |
| **Alpha** | Excess return | Actual - [r_f + β(market - r_f)] |

### Optimization Capabilities

- **Maximum Sharpe Portfolio**: Finds the tangency portfolio on the efficient frontier
- **Minimum Variance Portfolio**: Lowest risk allocation
- **Efficient Frontier**: Generates 50 portfolios across the full risk spectrum
- **Equal Weight Baseline**: Naive 1/N diversification for comparison
- **Constraints**: Long-only (default); long-short supported

### Visualizations

- **Efficient Frontier Chart**: Interactive scatter plot with Capital Market Line
- **Monte Carlo Chart**: 2,000 simulated portfolios colour-coded by Sharpe ratio
- **Benchmark Comparison Chart**: Cumulative return vs. SPY over the chosen time period
- **Correlation Heatmap**: Before vs. after optimization side-by-side comparison
- **Allocation Pie Charts**: Current vs. optimal weight breakdowns
- **Risk Metrics Dashboard**: Key metrics with colour-coded interpretation
- **Sector Concentration Warning**: Highlights over-concentration in a single sector

### Additional Features

- **Time Period Selector**: 1m, 3m, 6m, 1y, 2y, 5y historical data windows
- **Sector Tags**: Each asset labelled with its GICS sector
- **Tab Switcher**: Toggle between Analysis and Optimization views when both are loaded
- **PDF Export**: Captures the entire results panel and downloads it as a PDF

## Installation & Setup

### Prerequisites
- Python 3.9 or higher
- Node.js 18 or higher
- npm

### Backend Setup

```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start the server
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

API available at: `http://localhost:8000`  
Interactive docs: `http://localhost:8000/docs`

### Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Application available at: `http://localhost:3000`

## Usage Workflow

### 1. Build a Portfolio
Add tickers (e.g., AAPL, MSFT, GOOGL) and set weights. Choose a historical time window (1m – 5y).

### 2. Analyze
Click **Analyze** to calculate expected return, volatility, Sharpe/Sortino ratios, VaR, CVaR, max drawdown, beta, alpha, and the full correlation matrix.

### 3. Optimize
Click **Optimize** to:
- Find the Max Sharpe, Min Variance, and Equal Weight portfolios
- Plot the efficient frontier
- Compare correlation structure before vs. after rebalancing

### 4. Monte Carlo
Click **Monte Carlo** to simulate 2,000 random allocations and visualise where they fall on the risk/return plane relative to the efficient frontier.

### 5. Benchmark Comparison
Click **vs SPY** to plot the cumulative return of the portfolio against the S&P 500 over the selected period.

### 6. Export
Click **Export PDF** in the header to download the current results panel as a PDF file.

## Key Concepts Demonstrated

### 1. Mean-Variance Optimization
The core principle of MPT: construct portfolios that optimise expected return for a given level of risk.

### 2. Efficient Frontier
The set of optimal portfolios that offer the highest expected return for each level of risk, or equivalently the lowest risk for each level of return.

### 3. Monte Carlo Methods
Empirical exploration of the portfolio space by sampling thousands of random allocations — confirms and contextualises the analytically derived frontier.

### 4. Benchmark-Relative Performance
Comparing cumulative returns against SPY quantifies whether active allocation decisions add value over passive index exposure.

### 5. Diversification & Correlation
The before/after correlation heatmap shows how rebalancing changes the dependence structure between assets — lower average correlation reduces portfolio variance.

### 6. Risk-Adjusted Returns
The Sharpe ratio demonstrates why evaluating returns relative to risk taken is more informative than absolute returns alone.
